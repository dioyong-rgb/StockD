## 데이터 의미와 범위

- 상단과 표 주변에 샘플 표시가 있으며, 실제 계정은 모두 미연결로 표시됩니다.
- 스마트스토어·쿠팡 판매자배송은 **채널 등록 재고**, 로켓그로스는 **주문가능 재고**로 구분합니다. 실제 보유량으로 합산하지 않습니다.
- 정상 수량 **0은 품절**입니다. 성공 후 실패 사례는 **이전 성공값 7개**를 보존하고 마지막 성공 09:02와 최근 시도 09:39를 따로 보여 줍니다.
- 첫 조회 실패·관리 미사용·미지원 가상 사례·지원 미확인의 수량은 **—**입니다. 실패를 0으로 바꾸지 않습니다.
- 관리 미사용 상세에는 표준형 옵션의 관리 여부를 설명하고, 9,999를 보유 수량으로 표시하지 않습니다.
- 주문 행의 부분 반품은 전체 3개 중 1개로 보존합니다. RG 주문은 출고 이후 조회 범위, 상태·클레임 지원 미확인을 표시하며 판매수량을 재고로 사용하지 않습니다.
- API 키 입력, 재고 수정·발송 처리·주문 상태 변경 기능이 없습니다. 외부 자산을 읽거나 외부 API를 자동 호출하지 않습니다. 공식 근거 링크는 사용자가 선택했을 때만 열립니다.

## 모바일 보완과 재확인

첫 검사에서 모바일 대시보드의 바로가기를 누르면 선택된 메뉴가 메뉴의 가로 영역 밖에 남는 문제를 확인했습니다. 작성 담당이 메뉴 영역의 가로 위치를 조정하도록 보완했습니다. 재확인 결과, 360px 화면에서 연결 안내와 상품 연결 바로가기를 눌러도 활성 메뉴가 보입니다.

비교·재고·주문·상품 연결 표 앞에는 **“표를 좌우로 움직여 확인하세요.”**를 추가했습니다. 검색과 필터로 표가 다시 만들어져도 안내가 중복 없이 유지됩니다.
