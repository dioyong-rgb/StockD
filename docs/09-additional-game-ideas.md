# 일일 확인 미션 이후의 새로운 게임 요소

검토일: 2026-10-05. 기존의 경험치·레벨·꾸미기·숙련 지도·퀴즈·주간 목표·팀 목표·배지와 다른 세 경험을 제안했다. 이후 사용자 요청에 따라 첫 항목을 HTML 시안에 구현했다. 이야기 24개 검사와 기존 기능 61개 검사가 통과했으며 개인 보상함과 선택형 미니게임은 미구현 추천이다. [연재 이야기 검증](11-serialized-story-verification.md)

## 1. 완료할 때마다 이어지는 짧은 이야기

**HTML 시안에 구현했다.** [연재 이야기 디자인](10-serialized-story-design.md)에 작은 이야기 초대줄, 별도 읽기 화면, 원작 장면과 누적 저장 규칙을 정리했다. 오늘 페이지 열기·재고·주문 확인을 모두 마치면 한국 날짜별로 상자 친구의 여행 다음 한 컷이 열린다. 완료한 날짜 5개로 한 에피소드를 구성하며 세 편·총 15컷으로 이어진다. 쉬었다 돌아오면 이미 열린 장면부터 다시 읽을 수 있다.

첫 완주에는 상자 친구가 지도를 발견하고, 두 번째 완주에는 다리를 건너며, 다섯 번째 완주에는 편지가 도착한다. 같은 날짜의 여러 번 완료·일일 삭제 후 재완료·여러 탭은 한 컷으로 처리한다. 저장된 최근 90일 일일 완료도 도입 시 반영하고, 해금된 이야기 누적은 일일 기록 보관 기간·일일 삭제·샘플 초기화와 분리하여 유지한다.

이야기는 허구로 표시한다. 캐릭터가 여행을 마쳤다는 표현을 실제 품절 해결·주문 처리 성공으로 해석하지 않도록 업무 표와 분리한다. 다음 장면은 선택해서 보고, 업무 화면을 자동으로 가리지 않는다.

Duolingo Adventures의 공식 안내는 캐릭터·이야기·주변 환경 상호작용을 게임 같은 경험에 연결한다. StockD의 한 컷 연재는 이를 짧게 응용한 설계 판단이며, 해당 서비스가 일일 업무 완료 후 같은 보상을 제공한다는 의미는 아니다. [Duolingo 공식 안내](https://blog.duolingo.com/adventures/)

## 2. 내가 정하는 개인 보상함

**미구현 추천이다.**

하루 미션 완주로 토큰 1개를 받고, 사용자가 원하는 보상을 직접 정한다.

- 토큰 1개: 10분 산책하기.
- 토큰 3개: 좋아하는 커피 한 잔 즐기기.
- 토큰 5개: 보고 싶던 영화 보기.

보상 사용은 개인 기록이며 서비스가 돈·상품을 지급하거나 자동 구매하지 않는다. 경험치로 성장하는 방식과 달리 사용자가 자신에게 줄 보상을 선택하고 토큰을 사용한다. 사용하지 않은 토큰은 쉬어도 유지한다.

날짜별 중복 지급 방지와 사용 내역 저장이 필요하다. 현재 90일 방문 기록과 별개로 누적 지급 날짜·잔액·사용 내역을 보존해야 하며, 날짜 기록이 보관 기간을 넘었다고 토큰을 다시 지급하지 않는다.

## 3. 하루를 마치는 선택형 미니게임

**미구현 추천이다.**

오늘 미션이 끝나면 원할 때만 짧은 상자 퍼즐을 연다. 상자 세 개를 맞는 자리에 놓거나 작은 길을 연결하는 별도의 놀이로, 약 20초 정도의 분량을 목표로 한다.

업무 판단 퀴즈와 달리 정답이 실제 주문·재고 상태를 뜻하지 않는 가벼운 퍼즐이다. 미니게임을 건너뛰거나 실패해도 일일 미션 완료를 유지한다. 시간 제한을 강제하지 않고 언제든 닫을 수 있게 한다. 드래그만 제공하지 말고 키보드나 위치 선택 버튼도 지원한다.

이번에는 **짧은 연재 이야기**만 추가하는 범위로 진행한다. 개인 보상함·미니게임을 추가하려면 별도 구현과 저장·접근성 검증이 필요하다. 위 요소의 참여·업무 효율 효과는 StockD에서 아직 검증하지 않았다.
