## 확인한 동작

- 첫 페이지 열기 `1/3`과 재고 확인 `2/3`에서는 이야기 `0/15`다. 주문 화면까지 확인하여 `3/3`이 되면 첫 한 컷을 열고 업무 화면은 유지한다.
- 한국 날짜마다 한 컷만 열며, 같은 날 반복 방문·새로고침·일일 기록 삭제 후 재완료·여러 탭 확인으로 중복 지급하지 않는다.
- 다음 날짜의 완료로 두 번째 컷을 열고, 하루를 쉬어도 이미 열린 이야기를 유지한다. 새로고침과 같은 브라우저의 재열기에서 누적 진행·마지막 열람 위치를 복원한다.
- 기존 최근 90일의 일일 `3/3` 기록을 도입 시 반영한다. 별도로 저장한 90일 이전 이야기 성취는 일일 기록 정리·삭제·샘플 초기화에 영향을 받지 않는다.
- 미래·잘못된 날짜·중복 날짜·잘못된 열람 위치·깨진 JSON을 정리한다. 이야기 저장만 차단한 경우에도 현재 열기에서 진행하고 저장 불가 안내를 표시한다.
- 다른 탭의 완료 날짜를 합치고 오래된 기록으로 덮어쓰는 상황에서 이미 얻은 성취를 복원한다.
- 버튼으로 선택할 때만 읽기 대화상자를 연다. 열린 컷을 다시 읽고 이전·다음·컷 선택으로 이동하며, 잠긴 컷과 범위 밖의 이동은 막는다. 키보드로 열고 Escape로 닫으면 원래 버튼으로 초점이 돌아간다.
- 읽기 창을 연 채 한국 날짜가 바뀌어 대시보드가 새로 그려져도 Escape 후 새 이야기 버튼으로 초점을 복귀한다. 다른 탭에서 다음 컷이 열리면 읽는 장면과 초점을 유지하면서 열린 수·다음 이동·컷 선택을 바로 갱신한다. 저장 횟수와 이벤트 횟수가 정착 후 추가로 늘지 않는 것도 확인했다.
- 15컷 상한·3편 구성을 확인하고 모든 컷의 고유 본문을 읽었다. 마지막 컷에서는 다음 이동을 비활성화하고 완결 안내를 표시한다.
- 품절 `0`, 첫 조회 실패 `—`, 이전 성공 수량 `7`, 실제 API 미연결, 로켓그로스 주문의 조회 범위·클레임 미확인 의미를 유지한다.
- 1440×1000·768×1024·360×800에서 가로 넘침·44px 조작 영역과 움직임 줄이기 설정을 확인했다.
