# StockD 샘플 미션 디자인

작성 기준: 2026-10-04. 기존 `prototype-design.md`와 `preview/index.html`을 바탕으로 한 HTML 시안 변경 기준입니다. 실제 API·DB 미연결, 조회와 샘플 내부 SKU 연결 범위는 유지합니다.

## 디자인 목표와 토큰

밝은 작업대 위에서 상자 안내 캐릭터와 함께 사례를 하나씩 확인하는 느낌을 만듭니다. 친근함은 미션 영역에 집중하고, 재고 표에서는 수량의 의미·출처·오류 상태가 가장 선명하게 보이도록 합니다. 접속이나 읽음에 보상하지 않고, 명시적 검토 기록과 실제 샘플 연결에만 진행을 부여합니다.

| 기본 색 | 값 | 사용처 |
| --- | --- | --- |
| 회백 | `#F5F7F6` | 페이지 바탕, 표 머리글 |
| 흰색 | `#FFFFFF` | 사이드바, 표, 미션 내용 영역 |
| 진한 녹회색 | `#21352F` | 제목·본문·상자 외곽선 |
| 민트 | `#247D68` | 주요 버튼, 선택 메뉴, 검토 진행 막대 |
| 황갈색 | `#976116` | 부족 재고, 조회 지연 등 기존 경고 의미 |
| 적색 | `#BD3C3C` | 품절 0, 조회 실패 등 기존 오류 의미 |

민트의 옅은 농도는 미션 머리글·선택 메뉴의 배경으로만 사용합니다. 보조 글자와 구분선은 녹회색의 옅은 농도로 만들고, 기존 채널 구분·지원 미확인 색은 상태 의미를 유지합니다. 완료 민트로 오류·미연결 상태를 덮어쓰지 않습니다.

- 글꼴: 기존 `Malgun Gothic`, `Apple SD Gothic Neo`, `Noto Sans KR`, sans-serif를 유지합니다. 외부 글꼴 요청은 추가하지 않습니다.
- 크기: 페이지 제목 28px, 미션 제목 20px, 영역 제목 18px, 표·본문 14px, 짧은 보조 안내 12~13px. 숫자는 자릿수 폭을 고정합니다.
- 배치: 제목·미션 문구는 좌측, 수량은 우측 정렬. 208px 사이드바와 현재 표 구조를 유지하고 대시보드 위쪽의 왼쪽 영역에 미션을 넣습니다.
- 간격: 8/12/16/24/32px. 미션 행은 16~20px 안쪽 여백과 가는 구분선을 사용합니다. 버튼 터치 영역은 44px 이상 확보합니다.
- 모서리: 입력·버튼 6px, 주요 내용 영역 10px. 그라데이션·반복 그림자·별도 경험치 카드·순위·접속 연속 기록은 넣지 않습니다.
- 선택 메뉴: 옅은 민트 바탕과 진한 민트 글자. 사이드바를 흰색으로 바꾸고 페이지 바탕과 가는 경계선으로 구분합니다.

## 화면 배치

세 미션은 자유롭게 선택할 수 있는 확인 항목입니다. 강제 순서 번호 대신 재고·조회·연결 아이콘으로 구분합니다. 진행률은 큰 운영 성과 숫자처럼 보이지 않게 제목 아래 짧게 표시합니다.

```text
┌───────────┬───────────────────────────────────────────────────┐
│ StockD    │ 샘플 데이터 · 실제 API 미연결                       │
│           ├───────────────────────────────────────────────────┤
│ 오늘 확인 │ 오늘 확인할 일                                     │
│ 통합 재고 ├─────────────────────────────────┬─────────────────┤
│ 통합 주문 │ 오늘의 샘플 미션          [상자] │ 실제 연결 상태  │
│ 상품 연결 │ 샘플 사례부터 하나씩 확인해요.   │ 스마트스토어    │
│ 알림 예시 │ 검토 진행 0/3  [━━░░░░░░░░]     │   실제 미연결   │
│ 연결·설정 ├─────────────────────────────────┤ 판매자배송 / RG │
│           │ □ 부족·품절 사례 검토 [사례 보기]│   실제 미연결   │
│           │ □ 조회 상태 사례 검토 [사례 보기]│                 │
│           │ □ 옵션 3개 연결 체험 0/3 [후보] │                 │
│           ├─────────────────────────────────┤                 │
│           │ 샘플 성취 [재고 검토][조회 검토] │                 │
│           │          [연결 체험]            │                 │
│           ├─────────────────────────────────┴─────────────────┤
│           │ SKU별 채널 재고 비교                               │
│           │ 상품 | 등록 재고 | 등록 재고 | RG 주문가능 재고     │
│           │ 품절·오류·이전 성공값과 샘플 표시는 그대로 유지     │
└───────────┴───────────────────────────────────────────────────┘
```

미션 제목 옆 또는 바로 아래에 `샘플`을 표시하고 하단에는 `진행은 현재 화면에서만 유지되며 새로고침하면 초기화됩니다.`를 둡니다. 960px 미만에서 기존 상단 메뉴 방식으로 바꾸고, 좁은 화면에서는 미션·실제 연결 상태를 한 열로 쌓습니다. 480px 미만은 미션 버튼을 설명 아래에 두고 배지를 줄바꿈합니다. 표는 기존 가로 스크롤을 유지합니다.

## 미션과 완료 기준

| 미션 | 사례와 안내 | 완료 조건 | 완료 표시 |
| --- | --- | --- | --- |
| 부족·품절 사례 검토 | `r1` 로켓그로스 주문가능 4개와 `n2` 스마트스토어 정상 조회 0개를 비교 | 사례 확인 영역의 `부족·품절 검토 기록` 버튼을 직접 누름 | `검토 기록됨` |
| 조회 상태 사례 검토 | `c2` 이전 성공값 7개와 `r2` 첫 조회 실패의 수량 `—`를 비교 | 사례 확인 영역의 `조회 상태 검토 기록` 버튼을 직접 누름 | `검토 기록됨` |
| 옵션 3개 연결 체험 | `c2`, `c3`, `n5`의 계정·원본 옵션 ID·내부 SKU 후보를 확인 | 기존 샘플 연결 승인으로 세 항목 모두 내부 SKU가 연결됨 | `샘플 연결 3/3` |

앞의 두 미션은 해당 필터로 이동한 뒤 두 사례의 핵심 정보를 담은 검토 영역에서 기록합니다. 검토 영역에는 `샘플 검토를 기록합니다. 재고·조회 오류는 해결되지 않습니다.`를 표시합니다. 기록 버튼은 실제 문제 해결 버튼처럼 보이지 않도록 명칭을 그대로 유지합니다.

메뉴 방문·상세 열기·필터 적용·알림 읽음만으로 미션을 완료하지 않습니다. 앞의 두 미션은 검토 기록만 바꾸고 수량·조회 상태를 수정하지 않습니다. 세 번째 미션은 선택 후보만 바꾸거나 알림을 읽어도 완료되지 않습니다. 연결 해제 후에는 연결 개수, 전체 진행률과 연결 배지가 즉시 현재 상태로 돌아갑니다.

진행은 완료한 미션 수 `0/3`, `1/3`, `2/3`, `3/3`으로 표시합니다. 연결 체험이 `1/3` 또는 `2/3`인 동안 해당 행에서 부분 진행을 알려 주되 전체 완료 미션 수에는 더하지 않습니다. 표시된 진행 막대에 접근 가능한 이름과 현재 값을 제공합니다.

## 성취 배지와 안내 캐릭터

배지는 미션 아래 작은 한 줄에 `샘플 성취`라는 제목으로 둡니다. `재고 사례 검토`, `조회 상태 검토`, `옵션 연결 체험` 세 개만 사용합니다. 미완료는 회백 바탕과 외곽선, 완료는 옅은 민트 바탕과 체크 표시로 구분하고 텍스트로도 상태를 알려 줍니다. 배지를 클릭해야 이해되는 별도 보상 화면은 만들지 않습니다.

안내 캐릭터는 외부 이미지 없이 작은 inline SVG 상자로 만듭니다. 64~72px 크기, 녹회색 선, 옅은 민트 몸체, 작은 눈과 짧은 입, 접힌 상자 덮개 정도로 제한합니다. 같은 정적 그림 옆 안내 문구가 진행에 따라 바뀌며 캐릭터가 계속 움직이거나 화면을 가리지 않습니다. 의미는 문구가 전달하므로 SVG는 장식으로 처리합니다.

| 진행 | 안내 문구 |
| --- | --- |
| 0/3 | `샘플 사례부터 하나씩 확인해 볼까요.` |
| 1/3 또는 2/3 | `진행을 기록했어요. 남은 사례도 확인해 보세요.` |
| 3/3 | `샘플 미션을 모두 확인했어요. 실제 재고·조회 상태는 그대로예요.` |

캐릭터는 미션 영역에만 두고, 재고 표의 품절·실패 행이나 실제 미연결 상태 옆에는 축하 표현을 붙이지 않습니다.

## 짧은 동작 피드백

- 검토 기록: `부족·품절 사례의 샘플 검토를 기록했습니다. 수량 상태는 그대로입니다.` 또는 `조회 상태 사례의 샘플 검토를 기록했습니다. 조회 오류는 그대로입니다.`
- 연결 승인: 기존 샘플 연결 승인 안내에 해당 행의 연결 개수 변화를 표시합니다. 세 개 완료 시 `옵션 3개의 샘플 내부 연결을 완료했습니다. 실제 계정은 미연결입니다.`
- 연결 해제: `샘플 연결을 해제했습니다. 연결 미션 진행도 함께 바뀝니다.`
- 전체 완료: 진행 문구와 배지만 갱신합니다. 폭죽·전체 화면 축하·소리·자동 이동은 없습니다.
- 초기화: 검토 기록·배지·연결 진행을 기존 샘플 초기화에 포함합니다. 새로고침 후에도 처음 상태로 돌아갑니다.

피드백은 기존 토스트의 짧은 문구와 약 160~200ms의 진행 막대 변화만 사용합니다. 보조 기술에는 상태 변화를 알리고, 움직임 줄이기 설정에서는 전환을 즉시 적용합니다. 초점 표시·대화상자 닫기·초점 복귀는 기존 동작을 유지합니다.

## 초안 자체 비평과 최종 조정

처음 생각한 미션별 큰 카드 세 개와 별도의 배지 보관함은 재고 표를 아래로 밀고 흔한 게임 대시보드처럼 보였습니다. 최종안에서는 기존 확인할 일 영역의 세 행을 재사용하고 배지는 하단 한 줄로 줄였습니다. 표와 실제 연결 상태가 미션과 같은 첫 화면 흐름에 남습니다.

진행률 `100%`와 녹색 완료만 강조하면 재고 문제를 모두 해결한 것으로 오해할 수 있습니다. 최종안에서는 `검토 진행 3/3`, `검토 기록됨`, `샘플 연결 3/3`처럼 완료한 행위를 명시하고 실제 오류·품절·미연결 표시는 유지합니다. 성취는 현재 시안의 확인 진행이며 실제 업무 성과 수치를 주장하지 않습니다.

캐릭터의 여러 표정·흔들리는 덮개·큰 말풍선은 성인 업무 도구의 밀도를 떨어뜨립니다. 최종안은 정적 상자 하나와 짧은 안내 문구로 제한합니다. 민트는 선택과 확인 진행에만 집중하고 경고색을 재사용해 기존 상태 구분을 유지합니다.

이 문서는 구현 전 디자인 결정입니다. HTML 구현·기능 검증·실제 화면 검토는 별도 담당이 수행하며, 완료 여부는 해당 검증 결과에 근거합니다.
