## 요약

네이버 스마트스토어와 쿠팡의 상품·재고·주문을 한 화면에서 조회하는 첫 버전을 준비→만들기→확인의 세 단계로 진행합니다.

## 1. 준비

현재는 설계와 문서 검토를 마쳤으며 앱·DB·수집기·샘플 데이터는 아직 없습니다. 실제 API 조회, GitHub 업로드, macOS·Linux 실행도 검증 전입니다.

스마트스토어와 쿠팡의 계정·상품/옵션 수·주문량을 확인합니다. 쿠팡 판매자배송과 로켓그로스를 모두 포함하되 조회 권한과 재고 의미를 따로 확인합니다. 키·권한·고정 발신 IP와 판매자센터 대조용 사례를 준비하고, 비밀값은 서버에만 등록합니다.

계정 준비와 공통 개발 환경 구축은 병행합니다. 승인이나 키를 기다리는 동안 샘플 데이터로 화면을 만들 수 있으며, 이 결과를 실제 연동 완료로 표시하지 않습니다.

## 2. 만들기

기존 TypeScript·Next.js 15·React 19 구성을 유지합니다. 공통 DB와 내부 SKU 연결을 먼저 만들고, 스마트스토어·쿠팡 조회 수집기와 재고·주문 화면을 연결합니다. 웹과 수집 워커를 분리하고 GitHub 공유용 버전·잠금 파일·설치 안내도 준비합니다.

실패해도 마지막 성공값을 유지하고 출처·확인 시각·오류를 표시합니다. 첫 알림은 앱 내부에서 제공합니다. 외부 재고 수정·발송 처리·주문 상태 변경은 포함하지 않습니다.

## 3. 확인

실제 계정으로 상품·재고·주문을 판매자센터와 대조하고, 전체 페이지 처리·중복 수집·부분 실패·워커 중단과 복구를 확인합니다. 모바일 화면과 권한·비밀값 보호도 검증합니다.

로켓그로스 주문은 출고 이후에 조회되는 제한을 표시합니다. 상태 변경·클레임 지원은 미확인이므로 확인한 기능만 완료로 기록합니다. 다른 OS 지원도 설치부터 DB·웹·워커 실행까지 재현한 범위만 인정합니다.
