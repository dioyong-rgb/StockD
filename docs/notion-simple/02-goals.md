## 요약

네이버 스마트스토어와 쿠팡의 조회 결과를 출처와 한계까지 확인할 수 있을 때 첫 버전의 목표를 달성한 것으로 봅니다.

## 1. 데이터가 맞는가

- [ ] 선택한 상품·옵션·주문을 실제 계정으로 조회해 같은 기준시각과 날짜 범위의 판매자센터 결과와 대조하고, 전체 페이지·주문 행·지원되는 클레임이 누락 없이 반영됩니다.
- [ ] 쿠팡 판매자배송 재고와 로켓그로스 주문가능 재고가 분리되고, 판매수량을 재고로 표시하거나 채널 수량을 실제 보유량으로 합산하지 않습니다.

신규 주문뿐 아니라 이전 주문의 상태 변경과 기존 클레임의 완료·철회도 확인합니다. 로켓그로스는 출고 이후에 조회되는 주문만 다루며, 상태 변경·클레임 지원은 미확인으로 표시합니다. 제공되지 않는 값은 추정하지 않습니다.

## 2. 화면에서 판단할 수 있는가

- [ ] 내부 SKU로 연결한 옵션을 채널·계정·배송 방식별로 찾을 수 있고, 미연결 옵션도 확인되며 모바일과 데스크톱에서 필터·페이지 이동이 동작합니다.
- [ ] 정상 재고 0·첫 조회 실패·성공 후 실패·미지원·재고 관리 미사용이 구분됩니다. 마지막 성공값·성공 시각·최근 실패·지연·샘플 출처가 함께 표시됩니다.

샘플 데이터는 운영 통계와 부족 재고 알림에서 제외합니다. 장애나 품절이 지속돼도 알림이 중복되지 않으며, 조회가 복구돼도 수량이 낮으면 부족 경보를 유지합니다.

## 3. 완료를 어떻게 확인하는가

위 항목은 완료 조건이며 현재 구현된 기능은 없습니다. 키·권한·고정 IP 확인과 실제 대조 증거가 있는 채널·기능만 실제 연동 완료로 기록합니다. 외부 재고 수정·발송·주문 상태 변경 없이 조회와 내부 설정만 제공합니다.

실패·중단 후 기존 성공값을 보존하고 복구 시 누락과 중복을 확인합니다. 권한을 서버에서 검사하고 비밀값이 브라우저·문서·로그에 노출되지 않아야 합니다. GitHub 공유와 다중 OS 지원은 설치·DB·웹·워커 실행을 재현한 뒤 완료로 기록합니다.
