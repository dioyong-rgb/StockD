## 이번에 연결할 쇼핑몰

네이버 스마트스토어와 쿠팡만 연결합니다. 쿠팡은 판매자배송과 로켓그로스를 구분해 조회합니다.

**현재는 연결 방법을 정리한 상태입니다.** 계정별 키·권한·발신 IP 확인과 실제 호출·판매자센터 대조는 아직 수행하지 않았습니다.

## 연결은 네 순서로 진행합니다

1. **준비:** 판매자 계정, 조회 권한, API 키와 등록할 서버 IP를 확인합니다.
2. **인증:** 서버에서 토큰 또는 서명을 만들어 요청합니다.
3. **조회:** 상품·옵션·재고·주문과 지원되는 클레임을 가져옵니다.
4. **검증:** 전체 페이지를 읽고 판매자센터와 대조한 뒤 실제 연동 완료로 기록합니다.

## 연결 안내 읽는 방법

아래 쇼핑몰별 안내에서 단계마다 공식 문서 링크를 확인할 수 있습니다. 공식 문서로 확인한 내용과 계정에서 추가 확인할 항목을 구분했습니다. endpoint와 호출 제한 등 개발 세부사항은 접어 두었습니다.

API 키·비밀키는 서버에만 등록합니다. 샘플 화면이나 연결 코드 작성만으로 실제 연동 완료라고 표시하지 않습니다.
