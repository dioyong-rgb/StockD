## 데이터가 이동하는 방법

기준 문서 검토일: 2026-10-03. 현재는 구현 전 설계이며 실제 API·DB 연동은 검증 전입니다.

스마트스토어·쿠팡 API → 별도 수집기 → 통합 DB → 재고·주문 화면 순서로 연결합니다. 수집기는 정해진 시간마다 쇼핑몰 정보를 가져와 저장하는 프로그램입니다. 화면은 DB에 저장된 마지막 성공 데이터를 읽습니다. 새 쇼핑몰은 공통 규칙에 맞는 연동 모듈을 추가하는 방식으로 확장합니다.

## 어떤 정보를 연결하나요?

상품명 대신 내부 SKU로 옵션을 연결합니다. SKU는 ‘검정 티셔츠 L’처럼 실제 판매 단위를 구분하는 우리 상품 코드입니다. 자동 연결 후보는 운영자가 확인한 뒤 확정하며, 연결되지 않은 옵션도 남겨 둡니다.

스마트스토어·쿠팡 판매자배송의 등록 재고와 로켓그로스 주문가능 재고는 따로 표시합니다. 실제 보유 재고는 향후 별도 연동 대상으로 두며 채널 수량을 합산하지 않습니다. 판매수량도 재고와 구분합니다.

재고 0, 조회 실패, 미지원, 재고 관리 미사용은 서로 다른 상태입니다. 실패하면 기존 수량과 마지막 성공 시각을 유지하고 지연·오류를 표시합니다.

지원되는 주문 상태 변경과 취소·반품·교환을 확인해 내부 DB에 반영합니다. 로켓그로스 주문은 출고 이후에 조회되며 상태 변경·클레임 지원은 아직 확인 중입니다. 쇼핑몰의 주문 상태를 바꾸는 기능은 제공하지 않습니다.

## 먼저 만드는 화면

통합 재고에서 옵션별 수량·배송 방식·확인 시각을 비교하고, 통합 주문에서 채널·기간·배송 방식·상태를 걸러 봅니다. SKU 연결 화면에서 옵션 관계를 확정합니다. 대시보드, 재고 부족·연동 오류 알림, 계정 연결·연동 상태·임계값 설정·알림 이력도 간단히 제공합니다. 샘플은 ‘샘플 데이터 · 실제 API 미연동’으로 표시합니다.
