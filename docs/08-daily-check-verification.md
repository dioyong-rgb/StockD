## 확인한 사용자 동작

- 새 한국 날짜에 처음 열면 페이지 열기가 자동 완료되어 `1/3`이다. 재고 화면 확인은 `2/3`, 주문 화면 확인까지 하면 `3/3`과 완료 도장을 표시한다.
- 완료 방문을 반복해도 중복 증가하지 않으며 새로고침과 동일 브라우저의 재열기에서도 저장 기록을 복원한다.
- 브라우저 시간대를 UTC로 설정한 검증에서도 기록은 한국 날짜를 사용했다. 가상 시계로 한국 자정을 넘겨 대시보드 `1/3`, 재고·주문 화면 각각 `2/3`으로 새날이 시작되는지 확인했다.
- 여러 탭의 기록을 합치고 이전 상태가 뒤늦게 저장되어도 완료 여부를 보존한다.
- 잘못된 JSON과 브라우저 저장 차단에 대응하고, 최근 90일을 벗어난 기록을 정리한다.
- 일일 기록 삭제는 오늘 페이지 열기만 남긴다. 기존 샘플 초기화는 일일 기록을 지우지 않는다.
- 기존 샘플 연습은 접기 영역을 열어 검토·연결 승인·배지·해제·초기화·키보드·초점 복귀를 다시 확인했다.
- 정상 조회 0, 첫 조회 실패의 `—`, 이전 성공 수량 7, 실제 미연결, 로켓그로스 출고 이후 주문 조회 범위와 클레임 미확인을 보존한다.
- 1440×1000, 768×1024, 360×800에서 화면이 전체 가로 폭을 넘치지 않고 넓은 표만 자체 스크롤한다. 키보드와 움직임 줄이기에서도 조작을 확인했다.

## 화면 확인

아래 최종 캡처를 저장했다. 데스크톱과 모바일 캡처를 직접 살펴 미션·도장·접기 영역·연결 상태의 배치와 글자 가독성을 검토했다. 좁은 날짜 칸의 기록 없음은 `—`로 표시하며 접근 가능한 이름과 툴팁에는 `기록 없음`을 유지한다.
