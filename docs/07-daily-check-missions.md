# 매일 확인 미션

작성 기준: 2026-10-05. `preview/index.html`의 매일 확인 미션에 대한 규칙과 디자인 기준입니다. 실제 실행 결과는 [매일 확인 미션 검증](08-daily-check-verification.md)에 기록합니다.

## 목적과 규칙 변경

매일 시안을 열고 재고·주문 화면을 한 번씩 방문하는 흐름을 가볍게 기록합니다. 사용자가 이번 요청에서 페이지를 열거나 해당 화면을 방문하면 미션이 자동으로 완료되도록 지정했습니다. 따라서 기존 `prototype-gamification-design.md`의 “메뉴 방문만으로 미션을 완료하지 않습니다” 원칙은 **새 매일 확인 미션에는 적용하지 않습니다**. 기존 세 샘플 연습은 명시적 검토 기록·연결 승인 조건을 유지합니다.

일일 진행과 완료 스탬프는 화면 방문 기록입니다. 실제 재고 점검의 정확성·조회 성공·신규 주문 유무·운영 성과를 나타내지 않습니다. 실제 API·DB·계정 연결이나 외부 쇼핑몰 재고 수정·발송·주문 상태 변경은 포함하지 않습니다.

## 자동 완료 조건

| 단계 | 완료 시점 | 표시 의미 |
| --- | --- | --- |
| 페이지 열기 | 해당 한국 날짜에 시안의 첫 화면을 엽니다. | 오늘 시안을 열었습니다. |
| 재고 확인 | 통합 재고 화면이 렌더되어 표시됩니다. | 오늘 재고 화면을 방문했습니다. |
| 주문 여부 확인 | 통합 주문 화면이 렌더되어 표시됩니다. | 오늘 주문 화면을 방문했습니다. |

미션은 날짜별 세 완료 여부로 계산하고 `0/3`부터 `3/3`까지 표시합니다. 새 날짜에 첫 화면을 연 직후에는 페이지 열기가 자동 완료되어 `1/3`입니다. 방문하는 순서는 자유이며 별도의 완료 버튼은 없습니다. 재고·주문 화면을 다시 방문하거나 검색·필터·상세를 반복해도 이미 완료된 단계는 다시 증가하지 않습니다.

당일 `3/3`인 날짜만 완료 스탬프를 표시합니다. 최근 7일 표시는 오늘을 포함한 한국 날짜 기준이며 작은 한 줄 영역으로 둡니다. 미완료 날짜는 완료 스탬프를 받지 않지만 벌점·진행 회수·연속 접속 요구는 없습니다.

## 날짜와 샘플 데이터의 구분

일일 기록 날짜는 브라우저에서 `Asia/Seoul` 기준 실제 날짜를 계산합니다. 실행 기기의 현지 시간대에 따라 날짜 기준을 바꾸지 않습니다. 한국 날짜가 바뀌면 새 일일 미션으로 전환하고 대시보드에서는 페이지 열기만 완료한 `1/3`부터 진행합니다. 재고 또는 주문 화면을 보고 있다면 새 날짜에 해당 화면의 확인도 함께 기록해 `2/3`이 됩니다. 30초마다 날짜 전환을 확인하며, 숨긴 탭은 다시 보이거나 창에 초점이 돌아올 때 확인합니다.

대시보드의 미션 날짜와 최근 7일 스탬프만 실제 한국 날짜를 사용합니다. 상품·재고 수량·주문·계정·조회 시각은 기존 HTML의 고정 가상 샘플입니다. 날짜가 바뀌어도 가상 주문을 실제 오늘 주문으로 해석하거나 조회 시각을 실제 수집 시각으로 바꾸지 않습니다. 정상 조회 `0`, 첫 조회 실패 `—`, 이전 성공값 `7`, 미지원·관리 미사용·지원 미확인·실제 미연결의 상태 의미를 그대로 유지합니다.

## 저장과 삭제

- 저장 위치는 브라우저의 `localStorage`이며 키는 `stockd.daily-checks.v1`입니다.
- 저장 내용은 날짜별 페이지 열기·재고 화면 방문·주문 화면 방문의 완료 여부뿐입니다. 상품·주문·계정·개인정보·키·토큰은 저장하지 않습니다.
- 오늘을 포함한 최근 90일 기록만 보관하고 범위를 벗어난 날짜는 제거합니다.
- 저장이 가능한 같은 브라우저에서 같은 시안을 새로고침하거나 다시 열면 당일 진행과 이전 완료 날짜가 복원됩니다. 파일 직접 열기와 HTTP 미리보기의 저장 위치는 별개이며, 서버 저장이나 브라우저·기기 간 동기화는 없습니다.
- 브라우저가 저장을 허용하지 않으면 화면과 자동 완료 흐름은 계속 사용할 수 있습니다. 진행은 현재 열기에서만 유지되고 이 제한을 화면에 안내합니다.

| 조작 | 일일 기록 | 다른 샘플 조작 |
| --- | --- | --- |
| 새로고침·같은 브라우저 재열기 | 저장 가능 시 복원 | 기존처럼 초기화 |
| 한국 날짜 변경 | 대시보드에서 `1/3`, 보고 있는 재고·주문 화면 확인까지는 `2/3` | 기존 샘플 데이터 의미 유지 |
| 연결·설정의 일일 기록 삭제 | 저장 기록 삭제 후 오늘 페이지 열기 `1/3` | 보존 |
| 기존 샘플 초기화 | 보존 | 검토·배지·샘플 연결·알림·샘플 설정 초기화 |

일일 기록 삭제와 샘플 초기화는 다른 버튼으로 제공합니다. 일일 기록 삭제 직후 현재 재고·주문 화면 방문을 자동 재완료하는 방식으로 기록을 복원하지 않고 오늘의 페이지 열기만 남깁니다.

## 기존 연습 보존

기존 재고 사례 검토·조회 상태 검토·옵션 3개 연결 미션은 대시보드의 `추가 샘플 연습` 접기 영역으로 옮기고 기본 상태는 닫힘입니다. 기존 세 미션의 진행과 배지 두 개는 일일 기록과 분리합니다.

재고·조회 연습은 사례 상세에서 검토 기록을 직접 남겨야 진행합니다. 연결 연습은 c2·c3·n5의 샘플 내부 연결을 승인해야 완료됩니다. `첫 연결 체험` 배지는 첫 승인, `한 바퀴 검토` 배지는 세 옵션 승인 시 획득하는 기존 HTML 규칙을 보존합니다. 연결 해제 시 현재 연결 진행은 감소하지만 당시 획득한 배지는 유지합니다. 이 연습 기록과 배지는 새로고침하거나 샘플 초기화를 누르면 초기화되며 일일 저장에는 포함하지 않습니다.

기존 설계 문서는 배지 세 개와 해제 후 배지 상태 복귀를 기술하지만 실제 HTML과 과거 검증 문서는 배지 두 개와 당시 성취 유지를 사용합니다. 이 변경에서는 HTML 규칙을 보존하며 과거 설계·검증·추천 문서를 수정하지 않습니다.

## 화면과 접근성

기존 민트와 녹회색을 사용합니다. 왼쪽에는 일일 미션 세 행과 최근 7일 완료 스탬프를 두고 오른쪽에는 기존 실제 연결 상태를 둡니다. SKU별 채널 재고 비교표는 그 아래에 유지합니다. 모바일에서는 미션과 실제 연결 상태를 한 열로 쌓고 넓은 표는 표 안에서 가로로 이동합니다.

각 행에는 단계 이름과 현재 완료 여부를 명확히 표시하며 재고·주문 행에서 해당 화면으로 이동할 수 있습니다. 이동 버튼은 44px 이상의 조작 영역과 키보드 초점 표시를 유지합니다. 진행률과 스탬프의 상태를 색만으로 전달하지 않습니다. `추가 샘플 연습`은 키보드로 열고 닫을 수 있어야 합니다. 효과를 끈 설정과 `prefers-reduced-motion`에서 사용할 수 있고 폭죽·소리·계속 움직이는 캐릭터는 추가하지 않습니다.

일일 진행이 `3/3`이어도 품절·조회 실패·실제 미연결 경고는 그대로 남습니다. 완료색으로 API 상태나 재고표의 오류 의미를 덮지 않습니다.

## 확인 기준

새 기능 검증은 별도 결과 기록에 남깁니다. 아래 기준이 정의되어 있다는 사실은 통과를 뜻하지 않습니다.

- 처음 열면 한국 날짜에 페이지 열기만 완료되어 `1/3`이고 재고·주문 방문으로 각각 한 단계씩 증가하는지 확인합니다.
- 같은 날 반복 방문·필터 적용·상세 열기·새로고침으로 중복 증가하지 않는지 확인합니다.
- 같은 브라우저 재열기 시 저장이 복원되고 한국 날짜 전환 시 새 미션으로 시작하는지 확인합니다.
- 오늘 포함 최근 7일의 `3/3` 날짜만 스탬프를 받고 최근 90일을 벗어난 기록이 제거되는지 확인합니다.
- 일일 기록 삭제 후 오늘 `1/3`, 샘플 초기화 후 일일 기록 보존이라는 차이를 확인합니다.
- 저장이 차단되거나 저장 데이터가 손상된 경우 시안이 계속 동작하고 유지 범위를 안내하는지 확인합니다.
- 기본 닫힘인 추가 샘플 연습에서 기존 세 미션과 배지 두 개가 기존 규칙대로 동작하는지 확인합니다.
- 1440px·768px·360px 화면과 키보드·움직임 줄이기 설정에서 조작할 수 있는지 확인합니다.
- 실제 API·DB 미연결, 고정 샘플 시각, 재고 상태 의미, RG 주문 조회 제한과 외부 쓰기 기능 제외가 유지되는지 확인합니다.
