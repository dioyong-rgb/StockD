# StockD 샘플 미션 검증

검증 기준: `AGENTS.md`, `docs/prototype-requirements.md`, 샘플 미션의 사용자 행동 결과 · 2026-10-04

## 검증 범위

시안의 미션은 샘플을 검토해 보는 진행 표시입니다. 재고 건강이나 API 연결 성공을 점수로 나타내지 않습니다. 실제 API·DB·계정은 연결하지 않으며, 외부 쇼핑몰 재고·발송·주문 상태를 변경하지 않습니다.

기존 검증은 `node scripts/verify-prototype.cjs`, 새 미션 검증은 `node scripts/verify-gamification.cjs`로 실행합니다. 브라우저는 로컬 Chrome이며 새 검증은 단일 HTML을 `file://`로 직접 엽니다. 외부 HTTP 요청이 발생하면 기록하고 차단합니다.

## 미션 완료의 의미

| 사용자 행동 | 기대 결과 |
| --- | --- |
| 첫 화면, 다른 메뉴 방문, 상세 열기 후 닫기 | 진행 0/3 유지 |
| 알림 예시 읽음 처리 | 미션·배지에 영향 없음 |
| 재고 미션 상세의 명시적인 검토 기록 | 해당 미션만 완료, 진행 1 증가 |
| 조회 실패 미션 상세의 명시적인 검토 기록 | 해당 미션만 완료, 진행 1 증가 |
| 이미 기록한 미션을 다시 검토 | 중복 증가 없음 |
| 옵션 후보만 선택 | 연결 미션 미완료 |
| 샘플 연결 1개 승인 | 첫 연결 배지 획득, 연결 미션은 미완료 |
| 샘플 연결 후보 3개 모두 승인 | 연결 미션 완료, 세 미션 완료 시 3/3 |
| 샘플 연결 해제 | 현재 진행 감소, 당시 획득한 배지 유지 |
| 초기화 또는 새로고침 | 검토·배지·샘플 연결·알림을 처음 상태로 복원 |

배지는 샘플 활동에서 획득한 당시 성취입니다. 획득·미획득 상태를 텍스트로 구분하고, 해제 후에도 현재 API·재고의 정상 상태로 오해하지 않도록 표시합니다.

## 함께 확인하는 회귀

- 미션을 모두 완료한 뒤에도 품절 `0`, 첫 조회 실패 `—`, 마지막 성공 수량 `7`, 성공/시도 시각, 미지원·관리 미사용·지원 미확인을 보존합니다.
- 실제 연결 상태는 계속 **실제 미연결**이며, RG 주문의 출고 이후 조회 제한과 상태·클레임 미확인을 유지합니다.
- 기본 `progress` 요소의 최댓값은 3이며, 표시 문구와 실제 값이 일치합니다.
- 실제 Tab 이동과 Enter로 미션 상세를 열고, Escape로 닫을 때 원래 버튼으로 초점이 돌아옵니다.
- 효과를 끈 설정과 시스템의 `prefers-reduced-motion`에서 미션·배지를 사용할 수 있으며, 움직이는 축하 효과가 없습니다.
- 음악, 스트릭, 순위표, 외부 쓰기 조작을 제공하지 않습니다.
- 1440×1000, 768×1024, 360×800에서 6개 메뉴와 미션 상세가 화면 전체를 가로로 넘치지 않습니다. 넓은 표는 해당 표 안에서 이동합니다.

## 결과 기록

기존 시안의 수정 전 기준 검증은 **24/24 통과**했습니다. 브라우저 오류와 자동 외부 요청은 모두 0건이었습니다. 기존 로컬 HTTP 미리보기 응답도 200이었습니다.

게이미피케이션 반영 후 검증은 **20/20 통과**했습니다. 기존 회귀 검증도 **24/24 통과**했습니다. 브라우저 오류와 자동 외부 요청은 모두 0건이며, 1440·768·360px 반응형과 키보드·ESC 초점 복귀, 초기화, 재고 의미 보존을 확인했습니다. 재현 가능한 항목별 결과는 `preview/screenshots/gamification-verification.json`에 저장했습니다.

새 검증은 화면에 나타난 결과와 사용자의 조작을 확인합니다. 내부 상태 객체나 특정 렌더링 함수의 구현을 직접 호출하지 않습니다. 실제 API·DB 연동, 운영 데이터의 정확성, 원격 배포를 검증한 결과는 포함하지 않습니다.
