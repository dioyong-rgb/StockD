# StockD HTML 시안 요건 검토

검토 기준: `AGENTS.md` 및 `docs/notion-simple/01~08` · 2026-10-04

## 시안의 목적과 범위

설계된 재고·주문 관리 화면의 구성과 사용 흐름을 미리 확인하는 단일 HTML 시안입니다. HTML 안에 스타일과 필요한 화면 동작을 포함하고, 실제 API·DB·계정 인증은 연결하지 않습니다. 샘플 데이터와 화면 내 변경은 미리보기 용도이며 저장되지 않습니다.

첫 범위는 네이버 스마트스토어, 쿠팡 판매자배송, 쿠팡 로켓그로스입니다. G마켓·옥션·11번가는 시안의 기능 메뉴에서 제외합니다. 상품·재고·주문 조회, 내부 SKU 연결, 앱 내부 알림과 설정을 보여줄 수 있으나 쇼핑몰 재고 수정·발송 처리·주문 상태 변경을 제공하지 않습니다.

## 꼭 보여줄 화면

| 화면 | 핵심 정보 | 시안 동작 |
| --- | --- | --- |
| 대시보드 | 확인할 항목, 재고 부족 예시, 연동 상태, 최근 확인 시각 | 관련 화면 이동 |
| 통합 재고 | SKU·상품/옵션, 채널·계정·배송 방식, 수량 의미, 확인 시각, 상태 | 검색·채널/상태 필터·상세 보기 |
| 통합 주문 | 주문 행·상품/옵션·수량, 채널·배송 방식, 조회한 원본 상태, 부분 클레임 | 기간·채널/배송 방식·상태 필터 |
| SKU 연결 | 미연결 옵션, 채널·계정·원본 옵션 ID, 내부 SKU 후보 | 운영자가 후보를 선택하는 시연 |
| 알림 | 부족 재고와 조회 오류의 구분, 이력, 현재 상태 | 읽음 처리 등 내부 화면 시연 |
| 연결·설정 | 계정별 연결 상태·최근 시도/성공·임계값 | 미연결 표시 및 연결 절차 안내 |

한 화면에서 모두 구현하기 어려우면 통합 재고를 첫 화면으로 두고, 나머지는 같은 HTML 내 탭이나 섹션으로 연결합니다. 개발 작업 목록 대신 실제 사용자가 판단할 수 있는 정보에 집중합니다.

## 데이터 의미를 지키는 표시 기준

- 페이지 상단에 **샘플 데이터 · 실제 API 미연동**을 항상 표시하고, 표의 행이나 표 전체 가까이에도 샘플 출처를 표시합니다. 실제 연동 완료·실시간 운영·동기화 성공으로 표현하지 않습니다.
- 실제 운영 통계·부족 재고 알림에는 샘플을 포함하지 않습니다. 시안의 예시 집계와 알림을 보여준다면 **예시**라는 표시로 운영 수치와 구분합니다. 연결 설정의 실제 상태는 **미연결**입니다.
- 네이버·쿠팡 판매자배송은 **채널 등록 재고**, 로켓그로스는 **주문가능 재고**로 표시합니다. 세 수량을 실제 보유 재고 하나로 합산하거나 판매수량을 재고로 사용하지 않습니다.
- 정상 수량 **0 = 품절**, 첫 조회 실패 **— + 조회 실패**, 성공 후 실패 **이전 성공값 + 확인 지연/실패 + 마지막 성공 시각**, 미지원 **— + 미지원**, 재고 관리 미사용 **— + 관리 미사용**, 지원 미확인 **— + 미확인**을 구분합니다.
- 성공 후 실패 예시는 기존 수량을 지우거나 0으로 바꾸지 않습니다. 최근 시도 시각과 마지막 성공 시각을 구분합니다. 빈 결과·오류·누락도 수량 0으로 만들지 않습니다.
- 네이버 표준형 옵션의 관리 미사용을 숫자 9,999만으로 판단하거나 실제 창고 수량으로 표시하지 않습니다.
- RG 주문에는 **출고 이후 조회되는 주문**이라는 제한을 가까이 표시합니다. 결제 직후 주문 전체를 확인한 것처럼 표현하지 않습니다. RG 상태 변경·취소/반품/교환 지원은 **미확인**으로 두고 상태를 추정하지 않습니다.
- 주문은 상품 행별 수량과 부분 클레임을 보존합니다. 변경 조회 건수를 신규 주문 건수로 표시하지 않습니다.
- 내부 SKU는 실제 판매 옵션 단위로 연결합니다. 자동 연결 완료를 주장하지 않으며 운영자가 후보를 확인하는 흐름으로 표시합니다. 원본 식별자는 계정과 함께 보여 줍니다.

## 사용자 흐름과 가독성

- 메뉴 이름은 간단한 한국어로 쓰고 현재 선택된 메뉴와 필터 조건을 명확히 표시합니다.
- 표의 수량은 오른쪽 정렬하고, 품절·지연·미지원 등 상태는 텍스트와 색을 함께 사용합니다.
- 상세 정보는 펼침이나 상세 패널에 넣습니다. 단위·배송 방식·데이터 확인 시각은 바로 판단할 수 있어야 합니다.
- 검색 결과 없음과 데이터 조회 실패는 다른 문구로 구분하고, 필터 초기화 수단을 제공합니다.
- 좁은 화면에서도 메뉴·검색·필터·표 내용을 사용할 수 있어야 합니다. 표를 가로로 스크롤한다면 주변 레이아웃은 화면 밖으로 넘치지 않아야 합니다.
- API 연결 안내는 준비→인증→조회→검증 순서를 요약하고 문서에 있는 공식 근거 링크를 연결합니다. 시안에서 실제 키를 입력받거나 비밀값을 노출하지 않습니다.

## 최종 확인 체크리스트

- [ ] 파일 하나를 열어 시안을 볼 수 있고 외부 API 호출·비밀값·고객 개인정보가 없습니다.
- [ ] 상단과 표 주변의 샘플 표시, 미연결 상태, 저장하지 않는 시연 안내가 보입니다.
- [ ] 재고 수량의 의미가 배송 방식별로 다르고 총 보유 재고로 합산하지 않습니다.
- [ ] 품절 0·조회 실패·이전 성공값·미지원·관리 미사용·미확인이 구분됩니다.
- [ ] RG 주문의 출고 이후 조회 제한과 상태·클레임 미확인이 보입니다.
- [ ] 외부 재고 수정·발송·주문 상태 변경 기능이 없습니다.
- [ ] 검색·필터·메뉴·상세 열기 등 표시된 조작이 실제 시안에서 동작하며, 실패/빈 결과에 맞는 문구를 표시합니다.
- [ ] 데스크톱과 모바일에서 읽을 수 있고 키보드 초점·레이블·상태 텍스트가 확인됩니다.
- [ ] 실제 구현·검증이 완료된 것처럼 표현한 문구가 없고 공식 근거 링크는 원본 문서에 있는 주소입니다.
