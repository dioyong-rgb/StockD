# StockD 화면 시안

`index.html`을 Chrome, Edge, Safari 같은 브라우저로 열면 됩니다. 스타일과 화면 동작을 HTML 파일 안에 포함하므로 앱 설치나 패키지 설치가 필요하지 않습니다.

## 미리 볼 수 있는 화면

- 운영 현황: 매일 확인 미션, 최근 7일 완료 스탬프, 상자 친구 연재 이야기, 추가 샘플 연습과 SKU별 판매 경로 재고 비교
- 통합 재고: 상품 검색, 판매 경로·상태 필터, 수량과 조회 이력
- 통합 주문: 주문 행, 판매 경로·기간·상태 필터, 부분 클레임
- 상품 연결: 원본 옵션과 내부 SKU 후보를 확인하는 흐름
- 알림 예시: 부족 재고·조회 오류 사례와 확인 이력
- 연결·설정: 계정의 미연결 상태, 연결 방법 안내, 예시 수량 기준

## 시안에서 사용하는 데이터

모든 상품·수량·주문·계정·조회 기록·알림은 예시입니다. 실제 쇼핑몰 API, DB, 로그인, 예약 수집은 연결하지 않습니다. 화면 안에서 적용하는 SKU 연결이나 알림 확인은 샘플 조작이며, 파일을 다시 열거나 새로고침하면 초기 상태로 돌아갑니다.

네이버·쿠팡 판매자배송의 등록 재고와 로켓그로스 주문가능 재고는 의미가 다르므로 총 보유 재고로 합산하지 않습니다. 로켓그로스 주문은 출고 이후 조회 범위를 가정하며 상태 변경·클레임 지원은 미확인으로 표시합니다.

실제 API 키·토큰·고객 개인정보를 입력할 필요가 없습니다. 쇼핑몰 재고 수정·발송·주문 상태 변경 기능도 포함하지 않습니다.

## 매일 확인 미션

한국 날짜(`Asia/Seoul`)마다 아래 세 단계가 자동으로 기록됩니다. 별도의 완료 버튼은 필요하지 않습니다.

| 단계 | 자동 완료 조건 |
| --- | --- |
| 페이지 열기 | 해당 한국 날짜에 시안을 엽니다. 첫 화면에서 1/3로 시작합니다. |
| 재고 확인 | 통합 재고 화면이 실제로 표시되도록 방문합니다. |
| 주문 여부 확인 | 통합 주문 화면이 실제로 표시되도록 방문합니다. |

같은 날 반복해서 열거나 방문해도 중복 증가하지 않습니다. 세 단계를 모두 방문한 날만 최근 7일 영역에 완료 스탬프를 표시합니다. 한국 날짜가 바뀌면 새 일일 미션이 시작됩니다.

**미션은 화면 방문 기록입니다.** 실제 재고를 검토했다거나 신규 주문이 있는지 확인했다는 운영 증거가 아닙니다. 실제 API·DB는 연결하지 않습니다. 오늘 미션 날짜는 실제 한국 날짜를 사용하지만 표의 상품·수량·주문·조회 시각은 기존 고정 샘플입니다.

브라우저 저장이 가능하면 날짜별 세 완료 여부만 `localStorage`의 `stockd.daily-checks.v1`에 최근 90일간 보관합니다. 같은 브라우저에서 같은 시안을 새로고침하거나 다시 열어도 일일 기록이 유지됩니다. 파일 직접 열기와 HTTP 미리보기는 저장 위치가 달라 서로 기록을 공유하지 않습니다. 상품·주문·계정·API 키는 저장하지 않으며 다른 브라우저·기기로 동기화하지 않습니다. 저장이 차단된 환경에서도 시안을 사용할 수 있고, 현재 열기에서만 진행을 유지한다는 안내가 표시됩니다.

연결·설정의 **일일 기록 삭제**는 저장된 일일 기록을 지우고 오늘의 페이지 열기만 완료된 1/3 상태로 시작합니다. 기존 **샘플 초기화**는 상품 연결·알림 확인·추가 샘플 연습 등을 초기화하며 일일 기록을 보존합니다. 두 조작 모두 이미 열린 연재 이야기를 보존합니다.

기존 설계에서는 방문만으로 보상하지 않았습니다. 사용자의 이번 요청에 따라 매일 확인 미션은 화면 방문을 자동 완료 조건으로 변경했습니다. 아래 추가 샘플 연습의 명시적 검토·연결 승인 조건은 유지합니다.

## 상자 친구의 연재 이야기

일일 미션이 한국 날짜 기준 `3/3`인 날마다 상자 친구의 여행을 한 컷씩 엽니다. 이야기는 **허구**이며 실제 품절 해결·주문 처리·API 정상 상태를 뜻하지 않습니다. `바람 우체국으로`, `등대의 작은 불빛`, `다음 길의 약속` 세 편이 각각 다섯 컷으로 구성됩니다.

대시보드의 짧은 이야기 초대줄에서 버튼을 눌러 장면 그림과 두 문장의 본문을 읽습니다. 미션 완료 시 이야기를 자동으로 띄우지 않습니다. 이미 열린 이전 컷은 다시 읽을 수 있고 잠긴 컷은 선택할 수 없습니다. 이야기 읽기 자체는 일일 진행이나 다음 컷 해금에 영향을 주지 않습니다.

같은 날짜의 반복 완료·일일 삭제 후 재완료·여러 탭 방문은 한 컷으로 취급합니다. 기능 도입 시 같은 브라우저에 보관된 최근 90일의 일일 완료 날짜도 최대 15컷까지 반영합니다. 쉬었다 돌아오거나 일일 보관 기간이 지나도 이미 열린 컷은 유지됩니다.

이야기 진행은 일일 기록과 별도의 `localStorage` 키 `stockd.story-progress.v1`에 완료 날짜 목록과 마지막으로 읽은 열린 컷 번호만 저장합니다. 상품·주문·계정·키는 저장하지 않습니다. 같은 저장 위치에서 새로고침하거나 다시 열면 복원하며 서버·다른 기기와 동기화하지 않습니다. 저장이 차단되면 현재 열기에서만 이야기 진행을 유지한다는 안내를 표시합니다.

일일 기록 삭제와 샘플 초기화는 이야기를 지우지 않습니다. 별도 이야기 초기화 버튼은 제공하지 않으며 브라우저의 해당 저장소를 전체 삭제하면 이야기 기록도 초기화됩니다. 그림은 HTML 안의 원작 장식용 SVG이고 외부 이미지 요청은 없습니다. 키보드·Escape 닫기·모바일·움직임 줄이기 기준은 기존 시안과 함께 유지합니다.

[연재 이야기 디자인](../docs/10-serialized-story-design.md)에 장면 원고와 해금·저장·화면 기준을 기록합니다. [연재 이야기 검증](../docs/11-serialized-story-verification.md)에서 이야기 24/22와 기존 기능 61/61 통과, 브라우저 오류·자동 외부 요청 0건을 확인할 수 있습니다.

## 추가 샘플 연습

기존 세 미션은 운영 현황의 **추가 샘플 연습** 접기 영역에 보관하며 처음에는 닫혀 있습니다. 부족·품절 사례, 조회 상태 사례, 옵션 3개 연결을 체험할 수 있습니다. 기존 진행과 배지 두 개는 현재 화면에서만 유지되며 실제 재고 건전성·API 연결 성공·운영자 성과를 뜻하지 않습니다.

- 재고·조회 미션은 사례 상세의 검토 기록 버튼을 눌러야 진행됩니다.
- SKU 연결 미션은 c2·c3·n5를 각각 승인해야 완료됩니다.
- 첫 샘플 연결 승인 시 `첫 연결 체험`, 세 옵션 연결 승인 시 `한 바퀴 검토` 배지를 획득합니다. 배지는 당시 수행 기록이며 연결 해제 후에도 유지되지만 현재 연결 미션 진행은 감소합니다.
- 조회 실패 `—`, 품절 `0`, 이전 성공값 `7`, 실제 미연결 상태의 의미는 유지합니다.
- 효과 사용을 끄거나 운영체제의 움직임 줄이기 설정을 사용하면 전환 효과를 줄입니다.
- 샘플 초기화와 새로고침은 추가 연습·배지·샘플 연결·알림 확인을 초기 상태로 되돌립니다.
