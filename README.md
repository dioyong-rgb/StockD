# StockD — 쇼핑몰 통합 재고·주문 관리

첫 버전은 네이버 스마트스토어와 쿠팡 판매자배송·로켓그로스의 상품·옵션 재고와 주문을 내부 SKU 기준으로 조회한다. G마켓·옥션·11번가는 이후 확장으로 둔다.

**현재 단계: 설계 및 HTML 화면 시안. 실제 앱·DB·수집기·쇼핑몰 API 연동은 아직 없다.** 모든 시안 데이터는 가상 샘플이며 실제 운영 통계·알림에 사용하지 않는다.

[HTML 시안](preview/index.html)을 브라우저로 열어 대시보드·통합 재고·통합 주문·상품 연결·알림 예시·연결/설정 화면을 살펴볼 수 있다. 설치가 필요하지 않다. **매일 확인 미션과 연재 이야기 진행은 브라우저 저장이 가능할 때 같은 브라우저에서 새로고침하거나 다시 열어도 유지된다.** 상품 연결·알림 확인·추가 샘플 연습 같은 다른 샘플 조작은 새로고침하면 초기화된다. 사용 안내는 [시안 안내](preview/README.md)를 참고한다.

매일 확인 미션은 한국 날짜(`Asia/Seoul`)를 기준으로 페이지 열기·재고 화면 방문·주문 화면 방문을 자동 기록한다. 3단계를 모두 방문한 날에는 최근 7일 영역에 완료 스탬프를 표시한다. 이는 화면을 방문한 기록이며 실제 재고 점검·신규 주문 유무·API 정상 여부를 증명하지 않는다. 오늘 미션 날짜는 실제 한국 날짜지만 표의 상품·수량·주문·조회 시각은 고정된 가상 샘플이다.

연재 이야기는 일일 미션 `3/3`인 한국 날짜마다 상자 친구의 허구 여행을 한 컷씩 연다. 세 에피소드·총 15컷이며 대시보드의 이야기 버튼으로 선택해서 읽는다. 완료 시 자동 팝업은 없고 열린 컷은 다시 읽을 수 있다. 이야기 누적은 일일 기록 삭제·샘플 초기화·90일 일일 보관 기간과 별개로 유지한다. 이야기 24개와 기존 기능 61개 검사가 통과했다.

## 첫 버전 원칙

- 쇼핑몰 API는 별도 수집기가 호출하고, 화면은 통합 DB를 읽는다.
- 재고 0, 조회 실패, 미지원, 재고 관리 미사용을 구분한다.
- 채널 등록 재고와 로켓그로스 주문가능 재고를 합산하지 않는다.
- 실패 시 마지막 성공값을 유지하고 오래된 데이터와 마지막 시도를 표시한다.
- 채널별 조회 지원 범위와 mock/fixture 표시를 유지한다.
- 쇼핑몰에 재고·주문 상태를 변경하는 기능은 첫 버전에서 제공하지 않는다.

개발 환경과 코드 규칙은 [AGENTS.md](AGENTS.md)를 따른다. 아직 실행 명령을 제공할 단계가 아니다.
