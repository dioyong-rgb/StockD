개인정보처리방침 (샘플 문안)

설계 문서의 방향을 화면 구성용으로 옮긴 예시이며 확정된 방침이 아닙니다.

목차

  1. 수집·저장하는 정보 (샘플)
  2. 저장하지 않는 정보 (샘플)
  3. 이 브라우저에만 저장되는 정보 (샘플)
  4. 연동 정보(API 키)의 처리 (샘플)
  5. 원본 응답의 보관 (샘플)
  6. 정보 주체의 요청 (샘플)
  7. 문의 (샘플)

1. 수집·저장하는 정보 (샘플)

서비스는 상품·옵션·재고·주문 조회에 필요한 정보와 상품 연결, 알림 설정, 알림 이력을 내부 저장소에 저장하는 것을 예정합니다. 정확한 항목은 확정 전입니다.

2. 저장하지 않는 정보 (샘플)

조회에 필요하지 않은 주소, 전화번호, 수취인명은 기본적으로 저장하지 않는 방향입니다. 추가 정보가 필요하면 목적, 열람 권한, 보관 정책을 별도로 정한 뒤에 다룹니다.

3. 이 브라우저에만 저장되는 정보 (샘플)

‘매일 확인’ 화면의 방문 기록과 이야기 진행 상황은 이용자의 브라우저(localStorage)에만 저장되며 서버로 전송하지 않습니다. 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다. 이 기록은 화면을 열어 본 날짜를 남기는 용도이며 재고 점검 완료를 뜻하지 않습니다. 정확한 항목과 보관 방식은 확정 전입니다.

4. 연동 정보(API 키)의 처리 (샘플)

API 키와 같은 비밀값은 서버에서만 처리하고 브라우저 화면에는 노출하지 않는 방향입니다. 이 시안에는 키를 입력하는 화면이 없습니다.

5. 원본 응답의 보관 (샘플)

쇼핑몰에서 받은 원본 응답은 필요한 필드만 남기거나 마스킹하는 방향이며, 보관 기간은 7일을 제안값으로 두고 운영 목적을 확인한 뒤 확정합니다.

6. 정보 주체의 요청 (샘플)

열람, 정정, 삭제 요청의 방법과 처리 기한은 검토 후 정합니다.
