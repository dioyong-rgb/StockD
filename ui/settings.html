연결·설정

계정의 실제 연결 상태와 연결 전 준비할 내용을 확인합니다.

실제 계정은 모두 미연결입니다. 이 시안은 키나 토큰을 입력받지 않고, 인증도 요청하지 않으며, 외부 호출도 하지 않습니다. 연결은 서버에서 준비하고 계정별 조회 결과를 검증한 뒤 완료로 표시합니다.

채널 계정

네이버와 쿠팡 계정의 연결 상태입니다. 모든 값은 가상 샘플입니다.

샘플

연결 절차 안내

실제 연결 시 서버에서 진행할 순서입니다. 이 시안에서는 실행되지 않습니다.

  1. 준비 · 계정과 권한 확인네이버는 앱 활성 상태, 상품·주문 API 그룹, 호출 IPv4를 확인합니다. 쿠팡은 WING API 키, 등록 IP, 판매자배송·로켓그로스 권한을 확인합니다.
  2. 인증 · 서버에서 진행네이버는 서버에서 OAuth2 토큰을 발급받고, 쿠팡은 서버에서 HMAC 서명을 만들어 요청합니다. 비밀값은 브라우저에 보내지 않습니다.
  3. 조회 · 상품, 옵션, 재고, 주문지원되는 범위와 수량 의미를 구분해 가져옵니다.
  4. 검증 · 판매자센터와 대조전체 페이지와 실제 조회 사례를 판매자센터와 맞춰 본 뒤 연결 완료로 기록합니다.

공식 근거 문서

링크는 걸지 않고 문서명만 적습니다. 판매자센터와 각 개발자 사이트에서 직접 찾아 확인해 주세요.

  • 네이버 커머스API: 인증 안내, 권한·제약 안내
  • 쿠팡 개발자센터: 오픈 API 키 발급 안내, HMAC 서명 생성 안내

내부 설정

기본값은 5입니다.

확인한 값: 5개
