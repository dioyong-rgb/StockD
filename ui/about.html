회사 소개

StockD는 네이버·쿠팡의 재고와 주문을 한곳에서 조회하는 읽기 전용 도구입니다.

현재 화면은 시안입니다. 모든 채널이 실제로 연결되어 있지 않으며, 표시되는 값은 가상 샘플입니다.

StockD가 하는 일

조회 전용

여러 쇼핑몰의 상품·옵션 재고와 주문을 한 화면에서 확인합니다. 쇼핑몰의 데이터를 바꾸는 기능은 없습니다.

상태 구분

품절, 조회 실패, 미지원, 지원 미확인을 서로 다른 상태로 보여 줍니다. 확인하지 못한 수량을 0으로 표시하지 않습니다.

마지막 성공값 유지

조회가 실패해도 마지막으로 성공한 값과 시각을 남겨 둡니다. 실패 응답이 성공한 값을 덮어쓰지 않습니다.

지원 채널

아래 채널은 모두 실제 미연결 상태이며 시안 화면입니다. 실제 API 연동과 검증이 끝나기 전에는 연동 완료로 표시하지 않습니다.

하지 않는 일

  • 쇼핑몰 재고 수정
  • 발송 처리
  • 주문 상태 변경

첫 버전은 조회와 앱 내부 알림만 제공하며 쇼핑몰에 쓰는 기능은 포함하지 않습니다.
