상태 예시

재고·주문 화면에서 만나게 되는 6가지 화면 상태입니다. 모두 샘플 예시이며 실제 조회 결과가 아닙니다.

조회 실패는 수량 0이 아닙니다. 조회 실패·미지원·미확인·관리 미사용은 수량을 0으로 바꾸지 않고 ‘—’로 비워 둡니다. 확인 지연은 마지막 성공값을 마지막 성공 시각과 함께 표시하며, 0은 정상 조회 결과가 0일 때(품절)만 표시합니다.

불러오는 중

불러오는 중입니다

재고 샘플을 준비하고 있습니다. 잠시 후 목록이 표시되는 상태의 예시입니다.

의미 조회 응답을 기다리는 중입니다. 보이는 때 화면을 처음 열거나 새로 조회를 시작한 직후입니다. 이 동안 수량은 비워 둡니다.

데이터 없음

표시할 재고 샘플이 없습니다

조회는 정상이지만 항목이 하나도 없는 상태의 예시입니다. 필터 결과 없음과는 다릅니다.

의미 조회에는 성공했지만 보여 줄 항목이 없습니다. 보이는 때 연결된 상품이나 주문이 아직 없을 때입니다. 조회 실패가 아닙니다.

조회 실패

재고 정보를 불러오지 못했습니다

조회 오류 상태의 예시입니다. 오류는 수량 0으로 바꾸지 않고, 확인 전 값은 비워서 표시합니다.

의미 쇼핑몰 조회가 실패해 값을 알 수 없습니다. 보이는 때 통신 오류나 응답 오류가 났을 때입니다. 이전 성공값이 없으면 수량은 ‘—’이며 0이 아닙니다.

확인 지연

최신 상태를 확인하지 못했습니다

최근 조회가 실패해 마지막 성공값을 보여주는 상태의 예시입니다. 아래 값은 현재 값이 아닐 수 있습니다.

의미 수량을 ‘—’로 비우지 않고 마지막으로 성공한 값을 유지해 보여 주는 중입니다. 보이는 때 최근 조회가 실패했거나 오래 갱신되지 않았을 때입니다. 현재 값이 아닐 수 있으니 마지막 성공 시각과 함께 봐야 합니다.

일부만 표시

일부 재고 정보만 표시됩니다

일부 채널의 조회가 끝나지 않은 상태의 예시입니다. 표시되지 않은 항목이 없다는 뜻이 아닙니다.

의미 일부 채널 결과만 도착했습니다. 보이는 때 네이버·쿠팡 중 한쪽 조회가 끝나지 않았거나 실패했을 때입니다. 보이지 않는 항목을 0으로 읽지 마세요.

조회 권한이 없는 상태의 예시입니다. 인증은 이 시안에 구현되어 있지 않습니다.

의미 현재 계정으로는 이 정보를 볼 수 없습니다. 보이는 때 로그인하지 않았거나 권한이 부족할 때입니다. 실제 인증은 후속 단계에서 연결합니다.
